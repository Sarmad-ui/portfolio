About

Who I am

I'm a Data Science student based in Lahore, Pakistan, currently in my third semester — but my curiosity keeps pulling sideways into security operations and endpoint detection. Instead of just reading about SOC work, I built one: a small home lab running Velociraptor across an Ubuntu server and a Windows VM client, so I could see telemetry collection and attack simulation up close rather than in theory.

On the learning side, I've worked through core security fundamentals — the CIA triad, IAM, cryptography, networking, the OWASP Top 10, malware basics, and incident response — thoroughly enough to turn my notes into structured study material for other beginners.

I see data science and security as two lenses on the same problem: understanding systems well enough to know when something's wrong. I'm early in both, and building in the open as I go.

Wazuh Automation with Suricata

GitHub → Watch Demo ▶

A home-lab SOC pipeline pairing Suricata as the network IDS with Wazuh as the SIEM — Suricata's eve.json alerts are ingested by Wazuh for centralized monitoring and dashboard visualization, while a custom Python response engine watches the same log and automatically adds the source IP of detected alerts to a local blocklist. Built and tested end-to-end on Ubuntu (WSL2), with Wazuh deployed via Docker Compose.
